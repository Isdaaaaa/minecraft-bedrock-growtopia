# 🌱 Minecraft Bedrock Growtopia-Like Server

A Growtopia-inspired game server built on Minecraft Bedrock, featuring dynamic world creation, player-owned worlds, and sandbox gameplay mechanics.

## 🎮 Concept

This project aims to recreate the core Growtopia experience within Minecraft Bedrock:
- **Dynamic World Creation** – Players can create and own their own worlds
- **Sandbox Gameplay** – Place, break, and interact with custom blocks
- **Economy System** – World locks, item trading, and player economy
- **Social Features** – Visit other players' worlds, cooperative building
